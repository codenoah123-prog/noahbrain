# noahflow Windows 테스트 앱

실행 파일: `noahflow-local.zip` (약 125KB).

1. https://nodejs.org/ 에서 Node.js 24 이상을 설치합니다.
2. 이 브랜치의 `downloads/noahflow-local.zip` 파일을 GitHub의 다운로드 기능으로 받습니다.
3. ZIP을 우클릭해 **모두 압축 풀기**를 선택합니다.
4. 폴더 안의 `start-windows.cmd`를 더블클릭합니다.
5. 자동으로 열린 브라우저에서 샘플 게시물과 댓글 자동화 설정을 테스트합니다. 사용 중에는 실행 창을 열어 두고, 종료는 Ctrl+C입니다.

현재 버전은 실제 인스타그램에 연결하거나 DM을 보내지 않는 테스트 앱입니다. 별도 유료 호스팅은 필요하지 않습니다. 개인 데이터베이스, 계정 정보, API 키는 배포 ZIP에 포함되어 있지 않습니다. Windows 실기기 검증은 아직 수행하지 못했습니다.
