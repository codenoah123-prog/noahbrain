# 개인 PC 실행 상태

현재 권장 검증 경로는 [Codespaces 브라우저 실행](CODESPACES.md)입니다. 기존 Windows ZIP은 배포 보류 상태이며, Windows 보안 경고의 원인이 해결되었다고 확인하지 못했습니다. 보안 기능을 끄거나 이전 파일을 허용·복원하지 마세요.

이 소스에서는 CMD·쉘 시작 파일과 브라우저 자동 실행 명령을 제거했습니다. 수정한 소스를 개인 PC에 배포하는 단계에서는 Windows 보안 검증이 추가로 필요합니다. 차단된 ZIP의 이름만 바꾸거나 그대로 다시 배포하지 않습니다.

검토를 마친 개발 소스를 실행하는 명령은 Node.js 24 이상에서 다음과 같습니다.

```bash
npm ci
npm run build
npm run local
```

브라우저는 자동으로 열리지 않습니다. 개인 PC에서는 터미널에 출력된 주소를 직접 엽니다. Codespaces에서는 3001의 Private 포트 미리보기를 사용하세요. 이 명령을 소개한 것이 Windows 백신 검증 완료를 뜻하지는 않습니다.

최종 개인 운영은 기존 PC와 SQLite를 사용하는 추가 월 결제 0원 목표이며, 월 10,000원 이상 필요한 구성은 제외합니다. 실제 Instagram 연동은 [별도 준비 안내](INSTAGRAM-READINESS.md)를 따릅니다.
