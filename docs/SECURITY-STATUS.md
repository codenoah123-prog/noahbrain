# Windows 다운로드 보안 검토 상태

상태: **배포 보류** (2026-10-26).

사용자가 Windows 브라우저에서 `다운로드 할 수 없음 - 바이러스가 감지됨` 메시지를 보고했습니다. 백신 제품과 정확한 탐지명은 아직 확인되지 않았습니다. 이 메시지만으로 악성 코드 여부나 오탐 여부를 확정할 수 없습니다.

확인 대상: `noahflow-local.zip`, 127548바이트, SHA-256 `41ddfcfaede8b4a71b96272fe7ca09e0ebb4a37da5a55cab0571ce5b83f54cc6`.

- GitHub 다운로드 브랜치의 최신 버전에서 해당 ZIP을 제거합니다. 이전 커밋은 조사 기록으로 남습니다.
- 사용자에게 보안 기능 해제, 허용 목록 등록, 복원 또는 차단 우회를 안내하지 않습니다.
- ZIP 무결성과 소스 일치는 확인했고, 코드 검토에서 명백한 악성 동작은 발견하지 못했습니다. 이는 백신 검사나 안전 보증이 아닙니다. 현재 환경에는 백신 엔진/서명 데이터베이스가 없습니다.
- 브라우저 자동 열기의 `rundll32.exe` 호출과 배치 실행기는 제거 가능한 불필요한 OS 실행입니다. 탐지 원인으로 확인된 것은 아닙니다.
- 다음 진단에는 Windows 보안 보호 기록 또는 사용 중인 보안 제품의 정확한 탐지명이 필요합니다. 원인 확인과 필요한 수정·검증 전에는 새 실행 패키지를 재배포하지 않습니다.

추가 관찰: 사용자는 Windows 보안 보호 기록에 이번 차단 항목이 없다고 답했습니다. 브라우저 또는 다른 보안 제품의 차단 가능성도 남아 있습니다. 공식 ClamAV 서명 배포 호스트 `database.clamav.net`에 대한 읽기 전용 연결 확인은 환경 프록시 `403`으로 차단되어 이 환경에서 백신 검사를 추가 실행하지 못했습니다.

브라우저는 Edge로 확인되었습니다. 보호 기록이 없다는 관찰만으로 SmartScreen, 브라우저 다운로드 검사 또는 다른 보안 제품 중 어느 것이 차단했는지는 확정하지 않습니다. Edge/Windows에서 해당 패키지의 실제 보안 검증을 수행할 수 있는 외부 검증 환경이 남은 전제 조건입니다.

## 소스 기반 브라우저 검증으로 전환

사용자가 2026-10-26 진행을 승인했습니다. CMD·쉘 시작 파일과 브라우저 자동 실행의 `child_process`/`rundll32` 호출을 제거했습니다. `package:local`은 파일을 만들지 않고 배포 보류 오류를 반환합니다. 변경된 소스만 별도 `codex/browser-test` 브랜치로 검토·게시하며 기존 ZIP, 데이터, `.env`, 빌드 번들은 포함하지 않습니다. Codespaces 환경은 사용자가 무료 잔량·유료 차단을 확인한 후 직접 생성합니다. 이 변경은 Windows 보안 탐지 해제 또는 백신 통과 확인을 뜻하지 않습니다.

## Cloudflare 웹 소스로 진행

사용자가 설치 파일 없이 웹으로 사용하는 방향을 요청했습니다. Cloudflare Worker/D1용 관리자 로그인·암호화 저장·서명 웹훅·조건부 전송 코드를 별도 브랜치로 준비합니다. 기존 ZIP과 Windows 실행기는 재배포하지 않습니다. 실제 사용자 계정 배포·Meta 발송은 자격 증명과 무료 계정 설정을 확인한 후 별도 검증해야 합니다. 이 작업은 이전 ZIP의 Windows 백신 판정이 해결됐다는 뜻이 아닙니다.
